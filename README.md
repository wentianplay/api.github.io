## 核心声明

1. 甲方将 `bintian.net` 全部权利（注册权、解析权、管理权、转让权及附属服务控制权）转让予乙方，用于抵偿等额彩礼债务。
2. 域名过户完成前，原彩礼债务不消灭；过户完成后，对应金额视为清偿完毕。
3. 若双方依法登记结婚，域名按夫妻财产约定作为共同财产处理（自登记之日起生效）。
4. 若未登记结婚，本页夫妻财产约定条款不生效，域名按抵债标的处理，可反向过户回甲方。
5. 本页内容为脱敏摘要，完整权利义务以双方签署的纸质原件及附件为准。

## 存证方式

- 协议原件：双方签字按印纸质件 + 附件（彩礼明细表、作价凭证、WHOIS 截图、转移确认函）
- 电子存证：建议另行办理可信时间戳 / 公证，本页面不替代电子存证报告
- 权属核验：以注册商后台 WHOIS 变更记录、转移确认函为准

## 争议处理

协商不成，按主协议第十条约定（仲裁 / 诉讼）处理。
